# 安全审查报告修复计划（全部可修项）

## Context

安全审查报告（4 高危 / 7 中危 / 7 低危）经三路源码核实：**H1–H4、M1–M7、L3/L5/L6 及 s.err 状态码 bug 在当前 HEAD (2656f45) 均未修复**；L1 / L2(ingress 部分) / L4 / L7 引用的文件（README 凭据、deploy/ 目录、.onedev-buildspec.yml、cmd/smoke）在本仓库全部历史中不存在（历史被重写过），无从修复，跳过。登录限速 + 常量时间比较已由 HEAD 提交完成，M3 只剩：去默认密码、哈希存储、首启强制设置。

已确认的关键事实：前端 `api.js` 用 `!res.ok || data.error` 判错（修 s.err 状态码对前端安全）；前端无 EventSource/WebSocket；chat/turns 请求 schema 设备端严格拒绝未知字段（M7 不能加 retention 字段，只做提示词隔离）；`deploy/` 不存在，部署文件只有根目录 Dockerfile + README。

## 修复项

### 1. H1 OAuth 回调 XSS — `internal/api/livechat_oauth.go`
- `oauthPopupHTML` 中 `%q` 拼内联 `<script>` 改为：`json.Marshal` 序列化 provider/ok/message 后，再转义 `<` `>` `&` 与 U+2028/U+2029 再嵌入（新增 `scriptJSON()` helper）。`?error=` 原文截断至 200 rune 后再进 msg。
- 回归测试：`error=</script><script>alert(1)</script>` 的回调响应不含未转义 `</script>`。

### 2. M2 教程页 `?base=` XSS — `internal/guides/guides.go`
- `Serve` 中 base 经 `html.EscapeString`（+ 去控制字符）后再替换 `{{BASE}}`；测试加注入用例。

### 3. H2 chat_downloader 任意命令执行 — `internal/livechat` + `internal/api/livechat.go`
- `ChatDownloader.Stream` 不再读 `Cfg.PythonPath/ExtraArgs`：解释器改为 `TRP_CHATDL_PYTHON` env（默认 `python3`），extra_args 彻底弃用。
- `saveLivechat` 解码后强制清空 `PythonPath/ExtraArgs`（客户端不可写）；`SourceConfig.Validate()` 对非空 python_path/extra_args 返回错误（防绕过 API 直调 SaveConfig，存量配置下次保存时被清空）。

### 4. H3 素材路径穿越 — `internal/role/manager.go` + `internal/api/roles.go` + `internal/api/role_media.go`
- `AssetPath` 清洗：`Clean` 后必须匹配 `roles/{角色ID}/文件名`（ID 限 `[A-Za-z0-9_-]+`、文件名限 `[\w.-]+`、无 `..`），非法返回 ""（各调用点自然 404）；新增 `ValidRoleID`，`SaveAsset`/`upsertRole` 校验角色 ID。
- `upsertRole` 校验 `icon/local_vrm/local_voice/local_vrms[].file/local_voices[].file` 全部匹配 `roles/{本角色ID}/` 前缀，非法 400。
- `roleClone` 的 ext 改用 `filepath.Ext` + 白名单（mp3/wav/m4a/ogg），修掉 multipart 文件名带 `/` 的写入穿越。
- 回归测试：PUT `{"icon":"../app.db"}` 被拒；AssetPath 穿越串返回 ""。

### 5. H4 桌面版 Host/Origin/token — `internal/api/api.go` + `internal/bootstrap/bootstrap.go`
- `api.Server` 增 `DesktopToken` 字段；`ServeDesktop` 生成 32 字节随机 hex，窗口 URL 改为 `?desktop_token=…`。
- `auth()` 的 Desktop 分支改为三步：① Host 必须为 `localhost:<port>`/`127.0.0.1:<port>`（从 `s.Origin` 解析），否则 403（杀 DNS rebinding）；② 若带 Origin 头必须与 `s.Origin` 同源，否则 403（杀跨站 text/plain POST 盲打）；③ `/api/*`（豁免 health/login/logout/auth-status/setup-auth/oauth/callback/guide 等无敏感项）要求 `X-Desktop-Token` 头匹配或已有 session，否则 401。
- 前端：`App.jsx` 启动时把 URL 中 `desktop_token` 存 sessionStorage 并 `history.replaceState` 去掉；`api.js`/`apiRaw` 有 token 时统一加 `X-Desktop-Token` 头；`VrmPreview.jsx` 唯一一处直连 fetch 改走同一 header。
- 回归测试：Desktop 模式错 Host 403、跨 Origin 403、无 token API 401、带 token 200。

### 6. M1 webhook 未配 secret — `internal/api/webhook.go`
- 未配 `socialdata_webhook_secret` 时直接 403 拒绝（保留日志提示）；`webhook_auth_test.go` 增用例。

### 7. M3 默认密码 — `internal/api/api.go` + `settings.go` + `login.html`
- 删除 `DefaultAuthPass` 兜底；user 兜底 admin 保留。
