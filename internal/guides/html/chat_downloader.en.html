chat-downloader · no-auth fallback

Open the chat-downloader repo

This source does not use OAuth. The server runs python3 -m chat_downloader and reads JSON lines from stdout.

  1. On the machine that runs this service: pip install chat-downloader (or pip3).
  2. On this page click New source, pick chat-downloader, and paste any live / VOD URL it supports (YouTube, Twitch…).
  3. Python path defaults to python3; set an absolute path if it is not on PATH.
  4. extra_args is passed through to the CLI, e.g. --start_time 0.

Official Twitch EventSub / YouTube Live API are stabler and lower-latency. Use this path when you cannot get an official token, or when you need VODs.

The child process is killed on stop; after a stream ends the Manager restarts it.
