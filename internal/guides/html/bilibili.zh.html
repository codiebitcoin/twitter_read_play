Bilibili · blivedm-go 弹幕

打开 blivedm-go 仓库

B 站没有对第三方开放的官方弹幕 pull API（开放平台 Open Live 只给主播自己的应用）。公开房间走 WebSocket 协议，本路用社区 SDK github.com/Akegarasu/blivedm-go。

  1. 频道填房间号（如 6）或 https://live.bilibili.com/6。
  2. 也可以点直播页上的「随机一路 B站」：从公开推荐列表抽一路正在播的。
  3. Cookie：优先在设置页「直播」顶部填一次全局 SESSDATA + bili_jct；单路留空会自动带上。B 站反爬改版后游客 getDanmuInfo 返回 -352，能连上但弹幕为空。
  4. 从已登录 live.bilibili.com 的浏览器开发者工具复制 Cookie（SDK 缺 SESSDATA 或 bili_jct 会报「账号未登录」）。

不要把 B 站账号密码写进配置。Cookie 只存在本机 SQLite，不要提交到仓库。

弹幕 / 醒目留言 / 礼物都会归一成同一条 Message（kind = text / superchat / cheer）。
