打开 Google Auth Platform

官方入口：Cloud Console · YouTube Data API v3 · OAuth 客户端

不要把 Google 账号密码交给本服务。只在浏览器里走官方授权码；密码不会进本机。

本次实操（fortest 项目）

项目名 fortest，项目 ID gen-lang-client-0945395730。可以换自己的项目，步骤相同。

  1. 用你自己的 Google 账号登录 Cloud Console（实操账号 you@example.com）。
  2. 选中项目 fortest。
  3. API 和服务 → 库 搜索并启用 YouTube Data API v3。成功后通知里会出现 youtube.googleapis.com。
  4. Google Auth Platform → 品牌：应用名称填 Codie Live Chat（同意页上显示的名字）；用户类型选 外部；发布状态保持 测试；联系邮箱用登录账号。
  5. 用户端 → 建立客户端 → Web application：
    • 已授权的 JavaScript 来源：{{BASE}}
    • 已授权的重定向 URI：{{BASE}}/api/livechat/oauth/google/callback
    Client ID / Secret 只在创建弹窗出现一次，立刻填到本页「直播」卡，不要写进仓库。
  6. 资料存取权 → 新增或移除范围，勾选下表两行，点「更新」再点 Save。成功提示：已保存资料存取权变更。
  7. 目标对象 保持测试中；把要点「允许」的 Google 账号加进测试用户。品牌联系邮箱有时已经在列表里；再加一遍小写邮箱可能报「不符合资格」，忽略即可。
  8. 回到本页粘贴 Client ID / Secret → 用 Google 登录 → 选账号 → 允许「查看 YouTube 账户 + 邮箱」。
  9. 成功后本页显示 ✓ 邮箱。之后新建 youtube_api 源可把 token / API Key 留空，自动带上这个账号。

权限怎么开

位置： Auth Platform → 资料存取权（Data Access）。新控制台不再走旧的「OAuth 同意屏幕」向导。

https://www.googleapis.com/auth/youtube.readonly读直播间与 liveChatMessages（拉弹幕）。
https://www.googleapis.com/auth/userinfo.email回显登录的是哪个 Google 账号。

对应后端开关必须先启用 YouTube Data API v3，否则授权后调接口报 403 SERVICE_DISABLED。

填到 Google 控制台的地址

JavaScript 来源：{{BASE}}

OAuth 回调：{{BASE}}/api/livechat/oauth/google/callback

必须和浏览器地址栏 origin 逐字一致（含 http/https、主机、端口、路径）。本地常见是 http://127.0.0.1:8088，不要写成 localhost 或漏端口。

别漏了这几步

  • 外部 + 测试：只有测试用户能点允许；refresh token 大约 7 天过期，需要重新登录。
  • 本机 Go 进程访问 oauth2.googleapis.com / youtube.googleapis.com 往往要走系统代理。macOS 上常见 127.0.0.1:7892。启动时带 HTTPS_PROXY=http://127.0.0.1:7892，否则换 token 会 context deadline exceeded。浏览器能打开 Google 不等于 Go 进程也能连上。
  • Token 存在本机 SQLite blobs livechat_oauth.json，不要把 data 目录提交到 git。
  • 退出登录只清 token，不删 Client ID / Secret。
  • 也可以只用 API Key（凭据 → API 密钥）不登录；配额默认 1 万单位/天，轮询较吃配额。
