YouTube no-auth · innertube

Open youtube-live-chat-downloader

The remote framework is vendored in third_party/livechat: fetch the watch page, extract a continuation token, then loop POST youtubei/v1/live_chat/get_live_chat. No Google OAuth or API Key.

  1. Channel = a currently live YouTube URL or 11-char video id.
  2. If YouTube is blocked, set HTTPS_PROXY on the server (e.g. http://127.0.0.1:7892).
  3. VODs / offline videos return stream not live — pick a live one.

This uses an unofficial innertube protocol and can break when YouTube changes the page. Prefer YouTube Live API when Google login is available.
