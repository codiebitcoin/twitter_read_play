twitch · 申请 EventSub 弹幕 OAuth

打开 Twitch 开发者控制台

官方文档：Twitch Authentication · EventSub WebSocket

不要把 Twitch 账号密码交给本服务。只在弹窗里走官方授权码。

申请步骤

  1. 打开 dev.twitch.tv/console/apps，用你的 Twitch 账号登录（和看直播的是同一个账号即可）。
  2. 点 Register Your Application。Name 随意（例如 Codie Live Chat）。
  3. OAuth Redirect URLs 填：{{BASE}}/api/livechat/oauth/twitch/callback
  4. Category 选 Application Integration。创建后打开应用，复制 Client ID，点 New Secret 生成 Client Secret。
  5. 回到本页粘贴 Client ID / Secret → 用 Twitch 登录。弹窗会申请 user:read:chat。
  6. 成功后本页显示 Twitch login 名。新建 twitch_eventsub 源可把 Client ID / Token 留空，自动用这个账号订阅频道弹幕。

权限

位置： 授权弹窗里由本服务请求，控制台不用单独勾 scope。

user:read:chat以该用户身份读频道聊天（EventSub channel.chat.message 等）。

填到 Twitch 控制台的地址

OAuth Redirect URL：{{BASE}}/api/livechat/oauth/twitch/callback

必须和浏览器地址栏 origin 逐字一致。本地常见 http://127.0.0.1:8088/api/livechat/oauth/twitch/callback。

Subscribe 类型（建弹幕源时勾选）

channel.chat.message普通弹幕（建议必选）
channel.chat.notification订阅 / raid / 公告
channel.cheerBits / Cheer
channel.subscribe新订阅
channel.subscription.gift礼物订阅
channel.subscription.message订阅留言

channel 填对方的 login 名（不是显示名）。登录账号必须能进那个频道的聊天（公开频道即可）。

别漏了这几步

  • Token 存在本机 SQLite blobs livechat_oauth.json，不要把 data 目录提交到 git。
  • 退出登录只清 token，不删 Client ID / Secret。
  • 弹窗被拦：浏览器地址栏右侧允许本站弹出窗口。
