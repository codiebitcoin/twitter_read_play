twitch · Apply for EventSub chat OAuth

Open the Twitch developer console

Docs: Twitch Authentication · EventSub WebSocket

Do not give this service your Twitch password. Sign in only through the official authorization-code popup.

How to apply

  1. Open dev.twitch.tv/console/apps and sign in with the Twitch account you watch chat as.
  2. Click Register Your Application. Name can be anything (e.g. Codie Live Chat).
  3. OAuth Redirect URLs: {{BASE}}/api/livechat/oauth/twitch/callback
  4. Category: Application Integration. After create, copy the Client ID and click New Secret for the Client Secret.
  5. Paste them here → Sign in with Twitch. The popup requests user:read:chat.
  6. The page then shows the Twitch login. New twitch_eventsub sources can leave Client ID / Token empty and reuse this account.

Permissions

Where: requested by this app in the popup. You do not tick scopes in the Twitch console.

user:read:chatRead channel chat as that user (EventSub channel.chat.message and friends).

Address to paste into the Twitch console

OAuth Redirect URL: {{BASE}}/api/livechat/oauth/twitch/callback

Must match the browser origin exactly. Locally this is often http://127.0.0.1:8088/api/livechat/oauth/twitch/callback.

Subscribe types (tick them when creating a source)

channel.chat.messageRegular chat (recommended)
channel.chat.notificationSub / raid / announcement
channel.cheerBits / Cheer
channel.subscribeNew subscribers
channel.subscription.giftGifted subs
channel.subscription.messageSub messages

channel is the other side's login name, not the display name. The signed-in account must be able to join that chat (public channels are fine).

Don't skip these

  • Tokens live in the SQLite blob livechat_oauth.json. Do not commit the data directory.
  • Sign-out clears tokens only; Client ID / Secret stay.
  • If the popup is blocked, allow popups for this origin.
