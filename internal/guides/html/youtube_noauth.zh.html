打开 youtube-live-chat-downloader

远程框架已集成进后台 third_party/livechat：拉直播页 HTML 抽出 continuation，再循环 POST youtubei/v1/live_chat/get_live_chat。不需要 Google OAuth / API Key。

  1. 频道填正在直播的 YouTube URL 或 11 位 video id。
  2. 国内访问 YouTube 必须给本服务设 HTTPS_PROXY（本机常用 http://127.0.0.1:7892）。
  3. 回放 / 未开播会报 stream not live，换一个正在播的链接。

这路靠非官方 innertube 协议，页面改版可能失效。有 Google 登录时优先用 YouTube Live API。
