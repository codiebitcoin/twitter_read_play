打开 chat-downloader 仓库

这路不走 OAuth。服务端本机调 python3 -m chat_downloader，从 stdout 读 JSON 行。

  1. 在跑本服务的机器上安装：pip install chat-downloader（或 pip3）。
  2. 本页「新建弹幕源」选 chat-downloader，频道填任意它支持的直播 / 回放 URL（YouTube、Twitch…）。
  3. Python 路径默认 python3；解释器不在 PATH 时改成绝对路径。
  4. extra_args 可透传 CLI，例如 --start_time 0。

官方 Twitch EventSub / YouTube Live API 更稳、延迟更低。这路只在拿不到官方 token、或要拉回放时用。

子进程随停止被杀掉；直播结束后 Manager 会重启子进程再拉。
