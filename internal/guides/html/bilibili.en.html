Bilibili · blivedm-go chat

Open the blivedm-go repo

Bilibili has no official third-party chat pull API (Open Live is for the streamer’s own app). Public rooms use a WebSocket protocol; this source uses the community SDK github.com/Akegarasu/blivedm-go.

  1. Channel is a room id (e.g. 6) or https://live.bilibili.com/6.
  2. Or click “Random Bilibili live” on the Live page: it picks one room from the public recommend list.
  3. Cookie is required in practice. After Bilibili’s anti-crawler change, guest getDanmuInfo returns -352: the WebSocket connects but chat stays empty.
  4. Copy cookies from a logged-in live.bilibili.com browser. You need at least SESSDATA and bili_jct (the SDK errors “not logged in” if either is missing).

Do not put a Bilibili password in config. Cookies stay in local SQLite — never commit them.

Danmaku / Super Chat / gifts are normalized to the same Message (kind = text / superchat / cheer).
